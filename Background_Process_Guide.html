🔧 Background Process & Configuration Guide

📋 What Happens When You Run the Application?

1. JVM Starts
   ↓
2. Spring Boot Initializes
   ↓
3. Reads application.properties
   ↓
4. Connects to MySQL Database
   ↓
5. Hibernate Creates/Updates Tables (User, LeaveRequest, Payroll)
   ↓
6. DataInitializer Runs (Creates demo admin & employee)
   ↓
7. Tomcat Server Starts on Port 8080
   ↓
8. Application Ready! 🎉
   ↓
9. Waits for HTTP Requests

⚙️ Required Configurations

1. Java Installation

What you need: Java Development Kit (JDK) 17 or higher

Why: Spring Boot 3.x requires Java 17+

Download: Oracle JDK or Eclipse Temurin

Verify: Open terminal and run:

java -version

Should show: java version "17.x.x" or higher

2. MySQL Database

What you need: MySQL Server 8.0+

Why: To store user, leave, and payroll data

Download: MySQL Installer

Setup:

-- Login to MySQL
mysql -u root -p

-- Create database
CREATE DATABASE ems_db;

-- Verify
SHOW DATABASES;

3. Application Configuration File

File: src/main/resources/application.properties

What to configure:

Property What It Does Your Value
spring.datasource.url Database connection URL jdbc:mysql://localhost:3306/ems_db
spring.datasource.username MySQL username root (or your MySQL user)
spring.datasource.password MySQL password ⚠️ UPDATE THIS!
spring.jpa.hibernate.ddl-auto Auto-create/update tables update (already set)
server.port Application port 8080 (already set)

4. Maven (Build Tool)

What you need: Maven 3.6+ (or use Maven Wrapper)

Why: To download dependencies and build the project

Option 1: Install Maven from maven.apache.org

Option 2: Use IDE's built-in Maven (IntelliJ/Eclipse)

Option 3: Use Maven Wrapper (no installation needed)

🔍 What Each Configuration Does

Database Configuration

spring.datasource.url

Tells Spring Boot where to find your MySQL database:

  • jdbc:mysql:// - Protocol
  • localhost:3306 - MySQL server address and port
  • /ems_db - Database name

Hibernate Configuration

spring.jpa.hibernate.ddl-auto=update

Automatically creates/updates database tables based on your Java entities:

  • create - Drop and recreate tables (data loss!)
  • update - Update tables, keep data ✅
  • validate - Only check if tables match
  • none - Do nothing

Thymeleaf Configuration

spring.thymeleaf.cache=false

Disables template caching during development so you see changes immediately without restarting.

🚀 Background Processes Running

Component What It Does Port/Resource
Embedded Tomcat Web server handling HTTP requests Port 8080
Hibernate/JPA ORM - Converts Java objects to SQL Database connection pool
Spring IoC Container Manages beans (Controllers, Services, Repositories) Memory
Thymeleaf Engine Renders HTML templates Memory
MySQL Connection Database connection for queries Port 3306

✅ Pre-Flight Checklist

Before running, ensure:

  1. ✅ Java 17+ installed (java -version)
  2. ✅ MySQL Server running
  3. ✅ Database ems_db created
  4. ✅ MySQL password updated in application.properties
  5. ✅ Port 8080 is free (not used by another app)

⚠️ Common Issues

Error: "Cannot connect to database"

Fix:

  • Check if MySQL is running
  • Verify database name is ems_db
  • Check username/password in application.properties

Error: "Port 8080 already in use"

Fix:

  • Change port in application.properties: server.port=8081
  • Or stop the application using port 8080

Error: "Java version mismatch"

Fix:

  • Install Java 17 or higher
  • Set JAVA_HOME environment variable

🎯 What Happens After Startup?

  1. DataInitializer runs - Creates demo admin and employee users
  2. Server listens - Waits for requests on http://localhost:8080
  3. Auto-redirect - Root URL redirects to /login
  4. Session management - Tracks logged-in users
  5. Database queries - Executes when you interact with the UI
