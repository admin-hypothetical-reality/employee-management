☕ Java Installation Guide

⚠️ Java is Required!
Your Spring Boot application needs Java 17 or higher to run.

Option 1: Eclipse Temurin (Recommended)

Step 1: Download Java 17

Click the button below to download Java 17 (LTS):

📥 Download Java 17 (Eclipse Temurin)

Choose: Windows x64 → .msi installer

Step 2: Install Java

  1. Run the downloaded .msi file
  2. Click "Next" through the installer
  3. IMPORTANT: Check the box "Add to PATH"
  4. Click "Install"
  5. Wait for installation to complete

Step 3: Verify Installation

Open a NEW Command Prompt (important!) and run:

java -version

You should see:

openjdk version "17.x.x"
Eclipse Temurin

Option 2: Oracle JDK

Alternative download from Oracle:

📥 Download Oracle JDK 17

Choose: Windows → x64 Installer

After Installing Java

1. Restart VS Code

Close and reopen VS Code completely

2. Run Your Application

In VS Code:

  • Open EmsApplication.java
  • Look for "Run | Debug" above the main method
  • Click "Run"

OR use terminal:

cd "d:\employee management"
.\mvnw.cmd spring-boot:run

3. Access Your Application

Open browser to:

http://localhost:8080/test

🆘 Troubleshooting

If "java -version" still doesn't work after installing:

  1. Close ALL Command Prompt and PowerShell windows
  2. Close VS Code
  3. Open a NEW Command Prompt
  4. Try java -version again

If PATH is not set automatically:

  1. Search for "Environment Variables" in Windows
  2. Click "Environment Variables" button
  3. Under "System variables", find "Path"
  4. Click "Edit"
  5. Add: C:\Program Files\Eclipse Adoptium\jdk-17.x.x-hotspot\bin
  6. Click OK
  7. Restart your computer

✅ Quick Check

After installation, verify these commands work:

java -version
javac -version

Both should show version 17 or higher.
