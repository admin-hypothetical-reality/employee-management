🗄️ MySQL Database Setup & Test Guide

Step 1: Connect to MySQL

In MySQL Workbench:

  1. Click on "Local root instance" (or any connection you see)
  2. Enter your MySQL password when prompted
  3. Click OK
⚠️ Important: Remember the password you enter! You'll need it for the application.

Step 2: Create Database

Method 1: Using SQL Query

In the query editor (the big text area), type:

CREATE DATABASE ems_db;

Then click the ⚡ lightning bolt icon to execute

Method 2: Using GUI

  1. Right-click on "Schemas" in the left panel
  2. Select "Create Schema"
  3. Name: ems_db
  4. Click Apply
  5. Click Apply again to confirm
  6. Click Finish

Step 3: Verify Database Created

Run this query:

SHOW DATABASES;

You should see ems_db in the list!

✅ Success! If you see ems_db, the database is created.

Step 4: Test Connection

Select the database:

USE ems_db;

Execute this query. If no error appears, connection works!

Step 5: Update Application Password

CRITICAL: Update your password in the application

Open: src/main/resources/application.properties

Change line 4 to match your MySQL password:

spring.datasource.password=YOUR_MYSQL_PASSWORD
Example:
If your MySQL password is admin123, change it to:
spring.datasource.password=admin123

Step 6: Test the Application

Start your Spring Boot application:

  1. In VS Code, click Run in EmsApplication.java
  2. Wait for: Started EmsApplication in X.XXX seconds
  3. Look for these messages: 
    ✓ Admin user created: admin@ems.com / admin123
✓ Demo employee created: employee@ems.com / emp123

Step 7: Verify Tables Created

Back in MySQL Workbench:

Run this query:

USE ems_db;
SHOW TABLES;

You should see 3 tables:

  • users
  • leave_requests
  • payroll
✅ Perfect! If you see these tables, everything is working!

Step 8: Check Demo Data

Verify demo users were created:

SELECT * FROM users;

You should see 2 users:

  • Admin User (admin@ems.com)
  • John Doe (employee@ems.com)

🎯 Quick Reference

Common MySQL Commands:

-- Show all databases
SHOW DATABASES;

-- Use a database
USE ems_db;

-- Show all tables
SHOW TABLES;

-- View table structure
DESCRIBE users;

-- View all data in a table
SELECT * FROM users;

-- Count records
SELECT COUNT(*) FROM users;

🐛 Troubleshooting

Error: "Access denied for user 'root'@'localhost'"

Solution: Your MySQL password in application.properties is wrong!

  1. Check what password you used to login to MySQL Workbench
  2. Update line 4 in application.properties with that password
  3. Restart the Spring Boot application

Error: "Unknown database 'ems_db'"

Solution: Database not created!

  1. Run: CREATE DATABASE ems_db;
  2. Verify with: SHOW DATABASES;

Can't connect to MySQL Workbench

Solution: MySQL service not running!

  1. Open Services (Windows + R, type services.msc)
  2. Find MySQL service
  3. Right-click → Start
