Employee Management System Implementation Plan

Goal Description

Build an Employee Management System using Spring Boot (Java) for both backend and frontend.

  • Admin: Manage employees, leaves, and payroll.
  • Employee: View leave status and salary history.
Architecture: This is a unified Spring Boot application using Thymeleaf for server-side HTML rendering. No separate frontend framework needed.

Detailed Class Design

1. Entities (com.ems.model)

User.java

Represents both Admin and Employees.

  • Long id (Primary Key)
  • String name
  • String email (Unique)
  • String password
  • String role (Enum: ADMIN, EMPLOYEE)
  • Double salary
  • String department
  • LocalDate joinDate

LeaveRequest.java

  • Long id
  • User employee (ManyToOne)
  • LocalDate startDate
  • LocalDate endDate
  • String reason
  • String status (PENDING, APPROVED, REJECTED)

Payroll.java

  • Long id
  • User employee (ManyToOne)
  • String month (e.g., "January 2024")
  • Double amount
  • String status (PAID, PENDING)

2. Services (com.ems.service)

UserService

  • User registerUser(User user)
  • User authenticate(String email, String password)
  • List<User> getAllEmployees()

LeaveService

  • LeaveRequest applyLeave(LeaveRequest request)
  • List<LeaveRequest> getLeavesByEmployee(Long employeeId)
  • List<LeaveRequest> getAllPendingLeaves()
  • void approveLeave(Long leaveId)

PayrollService

  • void generatePayroll(Long employeeId, String month, Double amount)
  • List<Payroll> getPayrollHistory(Long employeeId)

3. Controllers (com.ems.controller)

AuthController

  • GET /login: Display login page.
  • POST /login: Authenticate and redirect to appropriate dashboard.
  • GET /logout: Logout user.

AdminController

  • GET /admin/dashboard: Display admin dashboard.
  • POST /admin/employees: Add new employee.
  • GET /admin/employees: List all employees.
  • POST /admin/leaves/{id}/approve: Approve leave.
  • POST /admin/payroll: Generate payroll record.

EmployeeController

  • GET /employee/dashboard: Display employee dashboard.
  • GET /employee/leaves: View my leaves.
  • POST /employee/leaves: Apply for leave.
  • GET /employee/payroll: View my salary history.

Frontend Design (Thymeleaf Templates)

Templates

  • login.html: Login form for both Admin and Employee.
  • admin-dashboard.html: Admin dashboard with employee management, leave approvals, and payroll generation.
  • employee-dashboard.html: Employee dashboard to view leaves and salary.

Verification Plan

Automated Tests

  • Unit Tests: JUnit tests for UserService and LeaveService logic.
  • Integration Tests: Spring Boot Test for controller endpoints.

Manual Verification

  1. Admin Flow: Login → Add Employee → View Employee List → Approve Leave.
  2. Employee Flow: Login → Apply Leave → Check Status → View Payroll.
