📋 Layer Breakdown

Controller Layer: Handles HTTP requests, routes to services, returns views

Service Layer: Contains business logic, validates data, coordinates operations

Repository Layer: Interfaces with database using Spring Data JPA

Model Layer: Defines database entities and their relationships

View Layer: Thymeleaf templates for rendering HTML pages
