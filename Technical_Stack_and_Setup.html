Technical Stack & Setup Guide

1. Technical Stack

Full Stack (Java)

  • Language: Java 17 (LTS)
  • Framework: Spring Boot 3.x
  • Build Tool: Maven
  • Database: MySQL 8.0
  • Template Engine: Thymeleaf (Server-side HTML rendering)
  • ORM: Spring Data JPA / Hibernate

Frontend Technologies

  • HTML5: Structure
  • CSS3: Styling
  • JavaScript: Client-side interactivity (optional)
  • Thymeleaf: Dynamic HTML generation

Development Tools

  • IDE: IntelliJ IDEA / Eclipse / VS Code
  • Database Client: MySQL Workbench
  • Version Control: Git

2. Setup Instructions

Prerequisites

Ensure you have the following installed on your system:

  • Java JDK 17+
  • Maven (or use the wrapper included in the project)
  • MySQL Server

Step 1: Database Configuration

1. Open your MySQL Client (Workbench or Command Line).

2. Create the database:

CREATE DATABASE ems_db;

3. (Optional) Create a specific user or use root:

CREATE USER 'ems_user'@'localhost' IDENTIFIED BY 'password';
GRANT ALL PRIVILEGES ON ems_db.* TO 'ems_user'@'localhost';
FLUSH PRIVILEGES;

Step 2: Project Setup (Spring Boot)

1. Navigate to the project root directory.

2. Open src/main/resources/application.properties and configure your DB credentials:

spring.datasource.url=jdbc:mysql://localhost:3306/ems_db
spring.datasource.username=root
spring.datasource.password=YOUR_MYSQL_PASSWORD
spring.jpa.hibernate.ddl-auto=update
spring.thymeleaf.cache=false

3. Build and run the application:

mvn clean install
mvn spring-boot:run

The application will start on http://localhost:8080.

Step 3: Accessing the Application

Open your web browser and go to:

http://localhost:8080/login

You should see the Login Page.

3. Dependencies (pom.xml)

Key Spring Boot dependencies:

<dependencies>
    <!-- Spring Boot Web -->
    <dependency>
        <groupId>org.springframework.boot</groupId>
        <artifactId>spring-boot-starter-web</artifactId>
    </dependency>
    
    <!-- Spring Data JPA -->
    <dependency>
        <groupId>org.springframework.boot</groupId>
        <artifactId>spring-boot-starter-data-jpa</artifactId>
    </dependency>
    
    <!-- Thymeleaf -->
    <dependency>
        <groupId>org.springframework.boot</groupId>
        <artifactId>spring-boot-starter-thymeleaf</artifactId>
    </dependency>
    
    <!-- MySQL Driver -->
    <dependency>
        <groupId>com.mysql</groupId>
        <artifactId>mysql-connector-j</artifactId>
    </dependency>
</dependencies>
